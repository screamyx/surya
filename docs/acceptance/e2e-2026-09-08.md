## Findings

- **E2E-LAUNCH-01, bug:** Select a new empty test project, leave its empty chat open, close and relaunch the app. Expected the same empty project view; seen an unrelated project's previous conversation while the test project remains selected and lists no sessions.
- **E2E-CHAT-01, bug:** Attach a text file using the paperclip and native file picker. Expected text attachment support required by acceptance; seen an images-only rejection.
- **E2E-CHAT-02, bug:** Attach a valid PNG and send it with a request to describe it. Expected a visible thumbnail; seen a blank rectangle before and after send, although the assistant correctly describes the image.
- **E2E-CHAT-03, design:** Scroll to an earlier response, then attach a file so the composer expands. Expected legible composer and validation message; seen transcript text through both surfaces. The error strip overlaps code text.

- **E2E-PERM-01, bug:** Open Settings and inspect its pages, then Needs you, after remembering a project-scoped permission. Expected a reachable list to inspect or revoke saved rules; seen no entry. Source corroboration: RulesPane is instantiated only in the inbox demo. The demo wording is not normal-app acceptance proof.

- **E2E-CARD-01, design:** Click Choose apples on the completed comparison card. Expected a readable selection acknowledgement; seen a raw card identifier, action name, and JSON payload in the user transcript. The action itself succeeds.

- **E2E-AGENT-01, bug:** Run the two-subagent mock fixture. Expected distinct child names in the tree; seen two Untitled chat rows during the run and after Done, while transcript chips have distinct task names.

## Findings

- **E2E-LAUNCH-01, bug:** Select a new empty test project, leave its empty chat open, close and relaunch the app.
  Expected the same empty project view; seen an unrelated project's previous conversation while the test project remains selected and lists no sessions.
  Issue: #202

- **E2E-CHAT-01, bug:** Attach a text file using the paperclip and native file picker.
  Expected text attachment support required by acceptance; seen an images-only rejection.
  Issue: #203

- **E2E-CHAT-02, bug:** Attach a valid PNG and send it with a request to describe it.
  Expected a visible thumbnail; seen a blank rectangle before and after send, although the assistant correctly describes the image.
  Issue: #204

- **E2E-CHAT-03, design:** Scroll to an earlier response, then attach a file so the composer expands.
  Expected legible composer and validation message; seen transcript text through both surfaces.
  The error strip overlaps code text.
  Issue: #205

- **E2E-PERM-01, bug:** Open Settings and inspect its pages, then Needs you, after remembering a project-scoped permission.
  Expected a reachable list to inspect or revoke saved rules; seen no entry.
  Source corroboration: RulesPane is instantiated only in the inbox demo.
  The demo wording is not normal-app acceptance proof.
  Issue: #206

- **E2E-CARD-01, design:** Click Choose apples on the completed comparison card.
  Expected a readable selection acknowledgement; seen a raw card identifier, action name, and JSON payload in the user transcript.
  The action itself succeeds.
  Issue: #207

- **E2E-AGENT-01, bug:** Run the two-subagent mock fixture.
  Expected distinct child names in the tree; seen two Untitled chat rows during the run and after Done, while transcript chips have distinct task names.
  Issue: #208

- **E2E-AGENT-02, bug:** Rejoin a running response after restarting the app, then Stop.
  Expected a stopped or settled tree status matching the transcript; seen Waiting for you while the transcript says Stopped and Needs you has no count.
  The later engine restart clears the agent tree.
  Issue: #209

- **E2E-FILE-01, bug:** Open Files, inspect the pane and right-click the test file.
  Expected create, rename and delete actions with a delete confirmation; seen only filter, file rows and editor.
  Source corroboration: tree handles navigation keys only and exposes no file mutation controls.
  Issue: #210

- **E2E-BROWSER-01, bug:** Leave the browser on the IANA example-domains page, ask the real agent to navigate the shared pane to example.org, and Allow its browser_open request once.
  Expected the visible pane and address to update; seen both stay on IANA after the run is Done, while the assistant claims Example Domain.
  The claimed result alone is not navigation proof.
  Issue: #211

- **E2E-VISUAL-01, design:** Open Appearance in Light and Dark.
  Expected secondary explanations to remain readily legible; seen faint helper text below the theme, accent, glass and motion labels.
  Increase the secondary-text token contrast and verify it in both themes.
  This is visual judgment, not a measured WCAG failure.
  Tracked with the existing text-tier issue; this observation does not establish that token aliasing causes the faint helper text.
  Issue: #172

- **E2E-NAV-01, design:** Open a chat with the Agents sidebar visible.
  Expected active indicators to distinguish the main destination from auxiliary panes; seen Home and Agents with identical selected fills, with Files adding another identical highlight when open.
  Differentiate these surface states.
  Issue: #212

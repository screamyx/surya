## Gotchas learned tonight, all verified

- Any `claude -p` or `claude auth` run from an agb-registered session inherits AGB_AGENT_ID and re-registers it under the child's pid. When the child exits the wake route dies and mail piles up silently. Always run probes with `env -u AGB_AGENT_ID -u AGB_AGENT_RECAP -u AGB_RUNTIME -u CLAUDECODE`. Recover with `agb register --id <me> --recap "..." --runtime claude` from your own pane, then prove it with a self-send.
- chrome-devtools-axi: always set a distinct CHROME_DEVTOOLS_AXI_PORT per session (10100 to 10999 worked), or you silently drive another session's bridge. Screenshots to /store fail silently; use /tmp.
- Lavish hides any element with class `mermaid` until Mermaid marks it processed, and Mermaid could not run inside its frame. Pre-render to SVG under another class.
- Vite blocks unknown hostnames; `allowedHosts` in vite.config.ts carries the tailnet domain.
- The shadcn resizable wrapper is stale against react-resizable-panels v4 (orientation, pixel sizes). The files builder worked around it.

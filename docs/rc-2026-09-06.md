## Known issues, in the order you will hit them

1. Windows renderer drops filled quads per frame (buttons, underlines, checkbox fills flicker). ROOT CAUSE FOUND 11:26 (PR #54): the gpui fork added a 32-byte fade field to Quad and PolychromeSprite and updated the Metal and WGSL shaders but not `shaders.hlsl`, so the DirectX stride is 192 bytes against a 160-byte shader layout and every quad after the first in a batch reads the wrong offset. Fix = 3 lines in the fork's HLSL plus a repin (fix/windows-quads-fork, in progress); RC1 ships with the flicker.
2. The browser pane is Linux-proven only; the CEF crate is excluded from CI (1.4 GB artifact), so a nightly job with CEF cached is owed.
3. The rename zeron -> surya lands last (decision 23, `scripts/rename-apply.sh`, PR #41). Until then the binary is still `zeron` and env vars are `ZERON_*`.
4. Pending permissions are lost on engine restart; a deleted chat denies its pending tool (by design).
5. Mac build parked (owner 06:08).
6. `cargo test` on Windows still fails: test-only unix code (source_control.rs tests, 13 files under engine/tests and harness/tests). `cargo build` is clean once PR #43 lands.
7. Never launch Xorg or any long-lived process from inside a `flock` block: the child inherits the lock fd and holds the lock for life (cost 40 min tonight). Use a lock-free shell or `flock -o`.
8. Agent mail ack race (found 11:23 on main's CI): a turn that completes before the engine records its run id loses that mail's ack. Fix PR fix/agent-mail-ack-race; if RC1 ships without it, a lost ack shows in `zeron mail drain` and the mail is not redelivered.
9. Test flakes in comet's own suites seen on CI tonight: harness/tests/claude.rs fixture chmod race (ETXTBSY), harness/tests/acp.rs steering order, engine empty_reasoning_deltas_are_heartbeats under load. Re-run once before believing a red.
